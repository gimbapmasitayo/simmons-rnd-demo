# 시몬스 R&D 포털 — 공개용 쇼케이스 (Vercel)

사내 포털(`1. 라돈 성적서 작성/`)을 **읽기 전용**으로 묶은 것입니다. 디자인과 화면은 같고, 다음이 다릅니다.

- 뉴스·경쟁사 제품·R&D 동향·전시회 일정·규격 요약집: 배포 시점의 **수집 스냅샷** (갱신하려면 `app/` 의 JSON 을 바꿔 다시 push)
- 성적서 실적: `?demo=1` 가상 자료 · 인증 현황: 익명화한 가상 자료 (실제 인증번호·제품명 아님)
- 성적서 생성·소급 등록·메모·설정 등 **모든 저장 기능은 꺼져 있음** (POST → 403)
- 아침 8시 자동 수집·주간 PDF 생성은 돌지 않음 (서버리스)
- 검색엔진 색인 금지 헤더(noindex)

## 배포

1. 이 폴더 내용을 GitHub 저장소 루트로 올립니다 (`api/`, `app/`, `vercel.json`, `requirements.txt`).
2. vercel.com → Add New → Project → 그 저장소 Import → 설정은 그대로 Deploy.
3. (선택) Settings → Environment Variables 에 `DEMO_SNAPSHOT_DATE=2026-10-06` 을 넣으면 데모 띠에 기준일이 붙습니다.
4. 이후 스냅샷을 바꾸려면 사내 폴더의 `뉴스기록.jsonl` `제품스냅.json` `동향기록.jsonl` `일정.json` `규격상태.json` 을 `app/` 에 덮어쓰고 push.

## 절대 올리면 안 되는 것
`.env`, `포털설정.json`, 실제 `발행기록.jsonl`, 실제 `인증현황.json`, `발행/` `확인용/` `자료/` 폴더(성적서·측정 원본).
`app/` 에는 그런 파일이 들어 있지 않습니다. 사내 폴더에서 파일을 추가로 복사할 때 이 목록을 확인하세요.
